# Checklist de lancement — Rank & Rent PACA

## Phase 1 : Infrastructure (Semaine 1)

### Hébergement
- [ ] Acheter un hébergement mutualisé (recommandé : o2switch — €7/mois tout illimité, serveurs en France)
  - Alternative : Hostinger Premium ~€3/mois
  - URL : https://www.o2switch.fr
- [ ] Configurer l'hébergement (accès cPanel/FTP)

### Domaines (.fr recommandé)
- [ ] Acheter les 5 domaines :
  - [ ] `avocat-divorce-toulon.fr` (ou `avocat-divorce-var.fr`)
  - [ ] `degat-eaux-marseille.fr` (ou `assechement-marseille.fr`)
  - [ ] `pompes-funebres-avignon.fr` (ou `obseques-avignon.fr`)
  - [ ] `serrurier-express-toulon.fr` (ou `serrurier-toulon-83.fr`)
  - [ ] `depannage-auto-marseille.fr` (ou `remorquage-marseille.fr`)
- [ ] Registrar recommandé : OVH (~€7-10/an par .fr) ou Gandi
- [ ] Configurer les DNS vers l'hébergement

### Numéros de téléphone
- [ ] Créer un numéro de tracking par site (pour mesurer les appels)
  - Option économique : Numéro OVH VoIP (~€1/mois) avec renvoi d'appel
  - Option pro : OnOff App (€4/mois par numéro, numéro local 04)
  - Option tracking complet : CallRail/Magnetis (~€30-50/mois pour 5 numéros)
- [ ] Configurer le renvoi d'appel vers ton numéro personnel (temporaire, avant de trouver un locataire)

## Phase 3 : SEO technique (Semaine 2-3)

### Google Search Console
- [ ] Créer un compte Google Search Console (ou utiliser existant)
- [ ] Ajouter et vérifier chaque domaine
- [ ] Soumettre le sitemap de chaque site
- [ ] Vérifier l'indexation (demander l'indexation de chaque page)

### Google Business Profile (CRUCIAL — le plus important pour le Local Pack)
- [ ] Option A (sans domiciliation) : Créer les profils APRÈS avoir trouvé un locataire — utiliser son adresse
- [ ] Option B (avec domiciliation) : 
  - [ ] Prendre une domiciliation commerciale à Toulon (~€20/mois)
  - [ ] Prendre une domiciliation à Marseille (~€20/mois)
  - [ ] Prendre une domiciliation à Avignon (~€20/mois)
  - [ ] Créer les GBP avec ces adresses
  - [ ] Demander la vérification (par courrier ou téléphone)

- [ ] Pages Jaunes (gratuit)

## Phase 5 : Prospection (Mois 2-3)

### Quand les sites commencent à ranker (page 1-2 Google)
- [ ] Identifier 20-30 prospects par niche (Google Maps page 2-3, Pages Jaunes)
- [ ] Envoyer l'email 1 (voir EMAIL-PROSPECTION.md)
- [ ] Relance J+4
- [ ] Relance J+10
- [ ] Appeler les non-répondants (3 min par appel)
- [ ] Proposer essai gratuit 2 semaines au premier intéressé
- [ ] Après essai : convertir en abonnement mensuel

### Alternative : déléguer la prospection
- [ ] Recruter un VA sur Fiverr/Upwork (~€50-100/mois)
- [ ] Lui donner la liste de prospects + templates d'emails
- [ ] Il envoie, tu conclus par téléphone
